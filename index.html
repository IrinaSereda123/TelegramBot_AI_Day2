Сегодня без Telegram: пишем одну программу ai.py, которая общается с языковой моделью прямо в PyCharm. С шага 5 каждое задание — небольшое изменение этого файла: показано, что добавить, и объяснено зачем.
В каждом шаге сначала короткая теория, потом задание. В каждом задании есть кнопка «Показать весь код» — там весь файл после этого шага, новые строки подсвечены зелёным. Кнопка ниже открывает весь код сразу во всех заданиях. Внизу страницы — справочник всех параметров.
Как работать в PyCharm
  1. Проект. File → New Project, имя my_ai, интерпретатор — Python 3.12.
  2. Терминал. Внизу открой Terminal (Alt+F12) — там выполняем pip install.
  3. Файлы. Правый клик по папке проекта → New → File (для .env, .gitignore) или New → Python File (для ai.py).
  4. Запуск. Правый клик по ai.py → Run 'ai' (Ctrl+Shift+F10). Ответ модели появится внизу, в окне Run. Там же вводишь вопрос.

Справочник: параметры запроса

Параметры пишутся в скобках у client.chat.completions.create(...) через запятую, например temperature=0.7. Не указал параметр — модель берёт своё значение по умолчанию. Не каждая модель поддерживает все параметры.

ПараметрЗначенияЧто делает
modelстрокаКакая модель отвечает, например openrouter/free или nvidia/nemotron-3.5-lightning:free. Пробуем сегодня.
messagesсписокСообщения, которые видит модель. У каждого есть role и content (текст). Пробуем сегодня.
role: system—Инструкция для модели: кем быть и как отвечать. Пишется первым сообщением. Пробуем сегодня.
role: user—Сообщение пользователя — твой вопрос. Пробуем сегодня.
role: assistant—Прошлый ответ модели. Нужен, чтобы модель «помнила» разговор.
temperature0 … 2, обычно 1Случайность ответа. 0 — почти всегда одинаково, 1.5 — креативно, выше — бывает чепуха. Пробуем сегодня.
max_tokens1 и большеСколько токенов модель может написать. Мало — ответ обрывается. Пробуем сегодня.
top_p0 … 1, обычно 1Модель выбирает только из самых вероятных слов, пока их общая вероятность не наберёт top_p. Меньше — осторожнее.
top_k0 и больше, обычно 0Модель выбирает только из k самых вероятных вариантов. 0 — без ограничения.
frequency_penalty−2 … 2, обычно 0Штраф за слова, которые уже часто встречались. Больше — меньше повторов.
presence_penalty−2 … 2, обычно 0Штраф за любое уже использованное слово. Больше — модель чаще переходит к новым темам.
repetition_penalty0 … 2, обычно 1Ещё один способ бороться с повторами. Больше 1 — меньше повторов.
min_p0 … 1, обычно 0Отбрасывает слишком маловероятные слова (относительно самого вероятного).
seedцелое число«Зерно» случайности: с одним seed ответы чаще повторяются. Не все модели поддерживают.
stopсписок строкМодель остановится, как только напишет одну из этих строк.

Что приходит в ответе

ПолеЧто это
response.choices[0].message.contentТекст ответа модели.
response.choices[0].finish_reasonПочему модель остановилась: stop — закончила сама, length — кончился max_tokens.
response.modelКакая модель ответила.
response.usage.prompt_tokensСколько токенов занял запрос (вопрос и инструкция).
response.usage.completion_tokensСколько токенов в ответе.

Если что-то пошло не так

Что видимЧто сделать
No module named 'openai' / 'dotenv'В терминале PyCharm: pip install openai python-dotenv
Нет OPENROUTER_API_KEYФайл .env лежит рядом с ai.py, называется ровно .env, внутри OPENROUTER_API_KEY=sk-or-v1-… без кавычек
AuthenticationError / 401Ключ скопирован не полностью или удалён. Создай новый в Keys и вставь в .env
NotFoundError / 404Опечатка в названии модели или модель убрали. Скопируй название из таблицы в шаге 4 или верни openrouter/free
RateLimitError / 429Лимит бесплатных моделей: 20 запросов в минуту и 50 в день на аккаунт. Подожди минуту или смени модель
Ответ пустой или NoneМодель потратила токены на «размышления». Увеличь max_tokens или смени модель
Программа «висит»Модель думает или ждёт твой ввод: посмотри в окно Run внизу PyCharm
